The pitch, in one line

The agent proposes. A human consents once, on their own device. A deterministic gate decides. The model never holds spending authority.

Setup

once, before you record
# .env — both must be your ngrok domain
PUBLIC_BASE_URL=https://your-domain.ngrok-free.dev
MCP_PUBLIC_BASE_URL=https://your-domain.ngrok-free.dev

npm run seed
npm run dev                                  # terminal 1 — dev, not start
ngrok http 3000 --url=your-domain.ngrok-free.dev   # terminal 2

Connector: claude.ai → Connectors → add https://your-domain.ngrok-free.dev/api/mcp. It must end in /api/mcp. When it asks to authorise, paste MCP_OAUTH_APPROVAL_TOKEN from .env.

Razorpay webhook: Dashboard → Settings → Webhooks → https://your-domain.ngrok-free.dev/api/webhooks/razorpay, secret RAZORPAY_WEBHOOK_SECRET, events payment.captured and payment.failed. Check it with npm run webhook:test.

If it breaks

  • No CSSServer booted on an old build. Restart with npm run dev.
  • Tool not foundConnector URL is missing /api. Retrying the prompt will not help.
  • Card refused“International cards are not supported” — use 4100 2800 0000 1007, or switch to Netbanking.
  • Stuck pendingNo capture webhook. Finish the take, then npm run webhook:test. Don’t narrate the stall.
  • Price changedThe five-minute lock expired while you talked. Say so and press again — it looks good on camera.

Recording notes

  • DoOne take. Cuts inside Beat 4 look like you hid a failure.
  • DoMove the mouse, then talk. Never both at once.
  • DoFace is optional. If you have a camera, small inset bottom-right, hidden during Beat 4. No camera is fine — a phone via Windows “connected camera” or Iriun works, and so does no face at all.
  • DoHeadset mic, sit close, record somewhere with soft furnishings. Judges forgive a plain screen recording; they do not forgive audio they cannot follow.
  • Donpm run seed after any failed take.
  • Don’tRead code aloud or narrate the file structure.
  • Don’tExplain JWS. Say “signed on the buyer’s device” and move on.
  • Don’tFake the wait in Beat 5. The real pause is the argument.
