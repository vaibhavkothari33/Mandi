Exposing the endpoint with ngrok

claude.ai cannot reach localhost

Claude on the web calls connectors from Anthropic’s infrastructure, not from your machine, so the merchant has to be on a public HTTPS address. Four steps, once.

1. Install and authenticate. Sign up at ngrok.com, copy the authtoken from the dashboard.

winget install ngrok.ngrok        # or: npm i -g ngrok
ngrok config add-authtoken YOUR_TOKEN

2. Claim your free static domain. The free plan includes one. Do this — it is the difference between re-adding the connector before every take and never touching it again.

# ngrok dashboard → Domains → Create Domain
# you get something like: mandi-demo.ngrok-free.app

3. Start the merchant with a bearer token, then the tunnel. Two terminals.

# terminal 1 (PowerShell)
$env:MCP_BEARER_TOKEN = -join ((1..32) | % { '{0:x2}' -f (Get-Random -Max 256) })
$env:MCP_BEARER_TOKEN          # copy this, you need it in step 4
npm start

# terminal 2
ngrok http 3000 --url=mandi-demo.ngrok-free.app

The variable must be set in the same terminal before npm start — the server process only inherits what existed when it launched.

4. Add the connector. Claude settings → Connectors → Add custom connector:

URL    https://mandi-demo.ngrok-free.app/api/mcp
Auth   Bearer <the token from step 3>

Verify before you record. The endpoint fails closed, and each response tells you exactly where you are:

What you getWhat it meansFix
503 remote_mcp_disabledThe server started without MCP_BEARER_TOKEN in its environmentSet the variable, then restart npm start
401 unauthorizedToken reached the server but doesn’t matchRe-copy it — no Bearer prefix in the field, no trailing newline
An ngrok HTML warning pageFree-tier browser interstitial, triggered by browser-like user agentsHarmless for the connector; if it does hit, upgrade or use the CLI take
ERR_NGROK_3200Tunnel is up but nothing is listening on port 3000npm start is not running, or it took a different port
Treat the tunnel as public. Anyone holding the URL and the token can drive the buyer side of your merchant. Keep both out of frame while recording, close the ngrok inspector at localhost:4040 (it shows the token on every request), rotate the token after the shoot, and stop the tunnel when you are done.

Most agentic commerce demos build the buyer — a chatbot that checks out. This is the other half: the merchant side, where the money actually moves.

Three of the eight aren’t buttons here. They need a completed purchase first, and each one burns a Razorpay test-mode payment link. Rather than quietly show five and imply that’s all of them, the page says which three are missing and why.

Consent I already granted, withdrawn. And revoking doesn’t just set a flag someone has to remember to read — it consumes the mandate, so the gate refuses it by the same single-use rule that stops a replay.

An ordinary Razorpay merchant, transactable by an AI buyer. The agent can do everything except decide to spend my money.
